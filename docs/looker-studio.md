# Отчёт Looker Studio

Название: «БЕЛАЯ ЛИНИЯ — hygiene_nov_2026». Три страницы. На каждой есть выбор периода, и он меняет все блоки этой страницы.

Имена, телефоны и e-mail на страницах отчёта не выводятся. Доступ «Просмотр» выдаётся e-mail заказчика.

В тексте ТЗ на месте третьей карточки и колонки успешных заявок стоит сломанная подстановка шаблона. По таблице статусов успешная заявка — это `visited`, «Пришёл на приём». В отчёте эта карточка названа «Пришли».

## Трафик

Источник: GA4.

- Карточки Sessions, Active users, Key events.
- График Sessions по дням.
- Таблица источников с Engagement rate.
- Фильтры Session source и Session campaign.

## Заявки

Источник: лист `leads`.

- Карточки «Всего заявок», «Новые», «Пришли». «Пришли» считаются по статусу `visited`.
- Столбчатая диаграмма по статусам.
- Заявки по источникам и по дням.
- Фильтр по статусу.

## Кампании

Объединение GA4 и таблицы. Ключи: source и campaign.

Столбцы: Sessions, `generate_lead` из GA4, число заявок из таблицы, заявки в статусе `visited`. Вычисляемое поле «Конверсия в заявку, %» — заявки, делённые на Sessions.

Снимок страницы после смены периода сохраните в `screens/datastudio/`.

## Аналитическая записка

После реальных проверок заполните `docs/report.md` числами из этих отчётов. Пустые клетки оставлены специально: подставлять непроверенные числа нельзя.
