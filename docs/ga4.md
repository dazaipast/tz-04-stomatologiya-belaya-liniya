# Ресурс GA4

1. Создайте ресурс с названием «БЕЛАЯ ЛИНИЯ — сайт».
2. Часовой пояс: Москва, `(GMT+03:00)`. Валюта: российский рубль.
3. Веб-поток: адрес сайта на Vercel. Включите расширенную статистику, включая взаимодействия с формами.
4. Идентификатор потока `G-…` подставьте командой `python tools/set_public_url.py`. Тег уже стоит в `<head>` всех страниц.
5. Зарегистрируйте семь параметров из `docs/events.md` как параметры события.
6. Ключевыми отметьте только `generate_lead`, `contact_click` и `messenger_click`.
7. Проверьте события в DebugView расширением Google Analytics Debugger. Снимки с раскрытыми параметрами сохраните в `screens/ga4/` под именем события, например `service_view.png`.
8. Перед сдачей отладочный режим в коде не нужен: `debug_mode` в проекте нет.

В параметры и в адрес страницы не попадают имя, телефон и e-mail.

## Исследования

В Explore создайте три исследования. Название каждого начинается с «БЕЛАЯ ЛИНИЯ ·».

1. Свободная форма. Строки: Session source / medium, Session campaign, Session manual ad content. Значения: Sessions, Engaged sessions, Key events. Фильтр кампании: `hygiene_nov_2026`.
2. Воронка, открытая: `page_view` → `cta_click` → `form_start` → `generate_lead`. Разбивка по Session source.
3. Путь. Начальная страница `checkup.html`, следующие три шага по Page title.
