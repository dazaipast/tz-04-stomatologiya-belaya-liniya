# Снимки экрана

Их делает исполнитель после подключения кабинетов. В репозитории папки уже есть.

- `screens/ga4/` — по файлу на событие из раздела 4.2, например `price_search.png`. На снимке событие и раскрытые параметры из DebugView.
- `screens/utm/traffic-acquisition.png` — отчёт Traffic acquisition, не меньше шести пар source / medium.
- `screens/instagram/` — комментарий, ответ, Direct и открытая ссылка для слов ЧЕК и ДЕТИ.
- `screens/datastudio/` — три страницы отчёта и проверка смены периода.
- `screens/lighthouse/` — отчёт главной в мобильном режиме: Performance не ниже 70, Accessibility не ниже 90, SEO не ниже 90.

Папка `screens/crm/` не используется: HubSpot по решению исполнителя не подключается.
